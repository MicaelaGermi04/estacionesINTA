# estacionesINTA

Paquete de R desarrollado como ejercicio práctico de programación colaborativa utilizando Git y GitHub.

## Descripción

El paquete tiene como objetivo permitir la lectura y el análisis de datos de estaciones meteorológicas.

Incluye funciones para:

- Descargar y leer archivos de estaciones meteorológicas.
- Calcular estadísticas descriptivas de temperatura.
- Generar gráficos de temperatura promedio mensual.

## Advertencia

**Este paquete es únicamente de prueba y tiene fines educativos.**

No está pensado para su utilización real ni para su distribución como herramienta de análisis meteorológico.
