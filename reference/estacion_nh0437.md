# Datos diarios de la estación NH0437 del INTA

Registros meteorológicos diarios entre 1970 y 2023.

## Usage

``` r
estacion_nh0437
```

## Format

Un tibble con 18929 filas y 35 variables, entre ellas:

- id:

  Código de la estación

- fecha:

  Fecha de la medición

- temperatura_abrigo_150cm:

  Temperatura media a 1,5 m, en °C
